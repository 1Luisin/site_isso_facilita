# Fontes do gerador social

Gelasio e Arimo, distribuídas sob SIL Open Font License 1.1; veja os arquivos de licença ao lado. Cópias locais dos arquivos originais, sem alteração:

- https://github.com/google/fonts/tree/main/ofl/gelasio — `Gelasio[wght].ttf`
- https://github.com/google/fonts/tree/main/ofl/arimo — `Arimo[wght].ttf`

Usadas somente pelo gerador de assets, com os contornos da instância padrão. Não são servidas pelo site. Mantenha as cópias versionadas para evitar variações ou acesso à rede no CI.
